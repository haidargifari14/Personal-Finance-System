# Roadmap to Version 1.0

| Version | Focus | Planned outcome |
| --- | --- | --- |
| 0.1 | Telegram Bot | Income, expense, confirmation flow, and Google Sheets integration. |
| 0.2 | Dashboard foundation | Navigation, theme, shared components, and live data access. |
| 0.3 | Visualization | Expense by category, cashflow trend, and monthly trend. |
| 0.4 | Analytics | Dedicated analytics page, drill-downs, and transaction analysis. |
| 0.5 | Planning | Budget planner, category limits, and budget-versus-actual views. |
| 0.6 | Forecasting | Cashflow forecast and decision-support signals. |
| 0.7 | Automation | Notifications and configurable financial reminders. |
| 0.8 | AI assistance | AI financial advisor with transparent, data-grounded guidance. |
| 0.9 | Enrichment | Receipt OCR and transaction extraction workflow. |
| 1.0 | Product release | Stabilization, documentation, testing, UX polish, and deployment readiness. |

## Near-term priority

1. Finish Expense by Category visualization.
2. Add Cashflow Trend and Monthly Trend.
3. Build the Analytics page on top of `AnalyticsService`.
